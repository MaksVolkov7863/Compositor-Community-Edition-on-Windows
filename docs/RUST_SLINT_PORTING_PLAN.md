# План портирования Compositor на нативный стек: Rust + Slint + wgpu

## 1. Выбор архитектурного стека и обоснование

**Выбранный стек:** `Rust + Slint + wgpu (DirectX 12 / Vulkan) + Rayon / SIMD`

### Почему этот вариант безоговорочно лучший:
1. **1-в-1 соответствие оригинальной архитектуре macOS**:
   - `SwiftUI` ➔ `Slint`: Декларативный синтаксис, реактивные свойства, биндинги состояний и независимость от оконного менеджера.
   - `Metal / MetalKit` ➔ `wgpu` (через DirectX 12 на Windows): Низкоуровневый доступ к GPU-пайплайну, шейдерам WGSL и текстурным операциям без оверхеда.
   - `Grand Central Dispatch (GCD) & C SIMD` ➔ `Rayon + wide / std::simd`: Детерминированная многопоточность для тайлового рендеринга и SIMD-векторизация режимов наложения без сборщика мусора (GC) и без блокировок Event Loop.
2. **Нулевой оверхед по памяти и ресурсам**:
   - Потребление RAM в простое: 15–30 МБ (вместо 180–300 МБ у Electron).
   - Запуск бинарника: < 80 мс.
   - Один компактный исполняемый `.exe` файл без внешних тяжелых рантаймов.
3. **Безопасность памяти**:
   - Надежный парсинг бинарных форматов (PSD, PSB, TIFF, HEIC, JPEG, PNG, EXIF) без риска переполнения буфера или UAF (Use-After-Free).

## 2. Архитектура целевой системы (Rust Workspace)

Проект организуется как мультикрейтовый Cargo Workspace:

```text
compositor-native/
├── Cargo.toml                      # Workspace root
├── crates/
│   ├── compositor-core/            # Ядро геометрии, цветовые модели, структуры слоев, undo/redo
│   ├── compositor-render/          # Вычислительный движок: Rayon, SIMD, тайлы, блендинг
│   ├── compositor-gpu/             # wgpu интеграция (DX12/Vulkan), WGSL-шейдеры, GPU Canvas
│   ├── compositor-format/          # Чтение/запись .comp (ZIP+JSON), импорт/экспорт PSD, TIFF, HEIC, PNG
│   ├── compositor-vision/          # Vision AI (ONNX Runtime / DirectML для Windows ML)
│   └── compositor-ui/              # Slint декларативные компоненты + входная точка приложения (main)
└── ui/
    ├── app.slint                   # Главное окно, докинг, тулбары
    ├── canvas.slint                # Область холста, интеграция с wgpu surface
    ├── panels/                     # Панели: Layers, History, Properties, Inspector, Navigator
    └── styles/                     # Fluent Design / Windows 11 Dark & Light токены
```

## 3. Детальный пошаговый план портирования

### ЭТАП 1: Подготовка инфраструктуры и структуры воркспейса
- **Шаг 1.1**: Инициализировать Rust Workspace (`Cargo.toml`) с целевым профилем оптимизации `opt-level = 3`, `lto = "thin"`, `codegen-units = 1`.
- **Шаг 1.2**: Настроить базовые зависимости:
  - `slint` (с бэкендом `winit` / `femtovg` или прямое встраивание `wgpu`).
  - `wgpu`, `bytemuck`, `pollster`.
  - `rayon`, `wide` (для портативного SIMD).
  - `serde`, `serde_json`, `zip` (для совместимости с форматом `.comp`).
  - `image`, `zune-image`, `kamadak-exif`.
- **Шаг 1.3**: Развернуть тестовый каркас нативных юнит-тестов с аналогичной нумерацией и структурой тестов upstream macOS (`tests/`).

### ЭТАП 2: Портирование `compositor-core` (Базовая модель данных)
- **Шаг 2.1**: **Геометрия и единицы измерения**:
  - `Point`, `Size`, `Rect`, `Transform2D` (аффинные матрицы для поворота, масштабирования, сдвига).
  - Конвертация единиц: `Pixels`, `Inches`, `Millimeters`, `Centimeters` с учетом DPI (`UnitConverter`).
- **Шаг 2.2**: **Цветовые пространства и пиксельные форматы**:
  - `Rgba8`, `RgbaF32` (линейное и sRGB пространства).
  - Поддержка 16-битных и 32-битных форматов для Camera Raw и HDR.
- **Шаг 2.3**: **Иерархия слоев и масок**:
  - Структура `Layer`: `id: Uuid`, `name: String`, `bounds: Rect`, `opacity: f32`, `blend_mode: BlendMode`, `visible: bool`, `locked: bool`, `clipping_mask: bool`.
  - Типы слоев: `RasterLayer`, `LiveTextLayer`, `VectorShapeLayer`, `AdjustmentLayer`, `GroupLayer`.
  - Маски: `RasterMask` (8-битный альфа-буфер, независимая трансформация или привязка к слою).
- **Шаг 2.4**: **Система истории (Undo / Redo)**:
  - Структуры транзакций: снапшоты метаданных слоев + COW (Copy-On-Write) блоки растровых данных через `Arc<PixelBuffer>`.
  - Лимит шагов истории, коалесценция (coalescing) быстрых правок слайдеров и кисти.

### ЭТАП 3: Портирование `compositor-render` (Вычислительный движок)
- **Шаг 3.1**: **Тайловая архитектура буфера (`TileMap`)**:
  - Разбиение больших холстов на тайлы 256x256 или 512x512 пикселей.
  - Ленивое выделение памяти только для непустых тайлов (Sparse Virtual Tile Array).
- **Шаг 3.2**: **Параллелизм на Rayon**:
  - Параллельная композиция тайлов по строкам и колонкам (`par_chunks_mut`).
  - Быстрое отсечение невидимых или пустых тайлов за пределами видимого вьюпорта.
- **Шаг 3.3**: **SIMD-ядро режимов наложения (Blend Modes)**:
  - Реализация 11 стандартных режимов (Normal, Multiply, Screen, Overlay, Darken, Lighten, Color Dodge, Color Burn, Difference, Soft Light, Hard Light) через AVX2/NEON с использованием крейта `wide`.
- **Шаг 3.4**: **Растровые фильтры и коррекции**:
  - Сепарабельное гауссово размытие (два прохода: горизонтальный и вертикальный с распараллеливанием по ядрам).
  - Motion Blur, Sharpen, Bloom, Vignette, Film Grain, Scanlines.
  - Дизеринг: Bayer 4x4, Floyd-Steinberg, Atkinson.
  - Adjustments: Levels, Curves, Hue/Saturation/Lightness, Brightness/Contrast, Exposure, Invert.

### ЭТАП 4: Портирование `compositor-gpu` (GPU Canvas на wgpu)
- **Шаг 4.1**: **Контекст рендеринга**:
  - Инициализация `wgpu::Device`, `Queue`, `Surface` с выбором DirectX 12 бэкенда на Windows (с возможностью Vulkan фолбэка).
- **Шаг 4.2**: **WGSL-шейдеры**:
  - Шейдер композитинга слоев в реальном времени с поддержкой аффинной трансформации текстурных координат.
  - Шейдер отрисовки сетки прозрачности (Checkerboard), 800% пиксельной сетки (Pixel Grid) и направляющих (Guides).
- **Шаг 4.3**: **Пайплайн динамической кисти**:
  - Сабпиксельная интерполяция мазков кисти, штампа (Clone Stamp) и лечебной кисти (Spot Healing).

### ЭТАП 5: Портирование `compositor-format` (Файловая система и совместимость)
- **Шаг 5.1**: **Формат `.comp` (Manifest 9)**:
  - Чтение и запись ZIP-пакета: `manifest.json`, каталог `layers/`, метаданные холста.
  - Обеспечение 100% бинарной совместимости с оригинальным macOS Compositor.
- **Шаг 5.2**: **Форматы изображений**:
  - Быстрый импорт/экспорт PNG, JPEG, WebP (`image`, `zune-image`).
  - TIFF импорт/экспорт (`tiff` crate с поддержкой сжатия Deflate и метаданных EXIF).
  - HEIC декодирование через `libheif-rs` (C-биндинг libheif под Windows MSVC).
  - Парсинг PSD и PSB (Large Document Format): слои, альфа-каналы, режимы наложения, группы.

### ЭТАП 6: Портирование `compositor-vision` (AI-сегментация)
- **Шаг 6.1**: **Интеграция с DirectML / ONNX Runtime**:
  - Использование нативного API Windows Machine Learning (DirectML) через ONNX-модель `birefnet` или `modnet`.
- **Шаг 6.2**: **Методы `select_subject` и `remove_background`**:
  - Препроцессинг тензора, запуск инференса на GPU без копирования из системной памяти.
  - Постпроцессинг маски: `refine_matte`, сдвиг краев (`shift_edge`), сглаживание и контраст.

### ЭТАП 7: Реализация интерфейса `compositor-ui` на Slint
- **Шаг 7.1**: **Стилизация под Windows 11**:
  - Создание Slint-темы с поддержкой темного и светлого режимов, скруглений Windows 11 и шрифтов Segoe UI Variable / Inter.
- **Шаг 7.2**: **Компоненты оконной системы**:
  - Кастомный заголовок окна (Frameless Custom Titlebar) с нативными кнопками управления окном и вкладками проектов.
  - Панель инструментов (Tools): Move, Marquee, Lasso, Magic Wand, Crop, Brush, Eraser, Clone Stamp, Healing, Gradient, Type, Shape, Zoom, Hand.
- **Шаг 7.3**: **Интерактивные панели**:
  - `LayersPanel`: Дерево слоев, перетаскивание (Drag & Drop), группировка, переключение видимости, блокировки, масок и режимов наложения.
  - `HistoryPanel`: Список состояний с возможностью мгновенного отката.
  - `AdjustmentsPanel`: Слайдеры с магнитным прилипанием к нулю (Zero-Snap) и живым превью.
  - `NavigatorPanel`: Миникарта с интерактивной рамкой вьюпорта.
- **Шаг 7.4**: **Холст и манипуляторы**:
  - Отрисовка рамки выделения (Marching Ants).
  - Манипуляторы трансформации (Bounding Box handles) со снэппингом к углам и направляющим.

### ЭТАП 8: Тестирование, бенчмаркинг и верификация паритета
- **Шаг 8.1**: Автоматический запуск нативных юнит-тестов всех 79 сьютов паритета.
- **Шаг 8.2**: Сравнение эталонных растровых буферов (Golden Snapshots) с оригинальным рендером macOS (побайтовая идентичность результирующих пикселей).
- **Шаг 8.3**: Прогон бенчмарка производительности (цель: композитинг 8K холста с 10 слоями при стабильных 60+ FPS).

## 4. Ожидаемый результат переноса

1. **Размер установщика**: < 20 МБ (вместо ~90 МБ у Electron).
2. **Потребление ОЗУ**: 20–40 МБ в базовом состоянии, линейный рост строго по используемым тайлам.
3. **Отклик интерфейса**: Мгновенный (время реакции на ввод < 2 мс).
4. **Совместимость**: Полная кроссплатформенная совместимость файлов `.comp` с macOS версией Compositor.
